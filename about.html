About April

I was building for the web before I knew to call it web development.

A writer's curiosity, an artist's eye, and a builder's persistence shape how I turn ideas into full-stack software.

The through line

Code is where all the pieces meet.

Long before I had a title for it, I was reading books about HTML and using code to personalize my own corner of the web. I thought I was simply being creative. Looking back, I was already discovering what still draws me to development: bringing structure, language, imagery, and interaction together into something complete.

I grew up around artists and builders. My father was an abstract sculptor and painter, and my extended family includes architecture, construction, engineering, and software. That environment taught me that creativity and technical structure are not opposites; the strongest work needs both.

I remain a writer, artist, and photographer as well as a developer. The writer asks what needs to be communicated. The artist considers how it should feel. The developer determines how it should work. The operator makes sure it keeps working after launch.

Education and evolution

From visual design to system architecture.

Each stage of my education added another layer: first how an experience looks and communicates, then how data and application logic make it work.

  1. Design foundation
    AAS, Web Design & Development. I developed a foundation in code, graphics, user experience, and responsive design. Instructors regularly selected my clean design work for program materials.
  2. Architecture shift
    CoffeeGrind relational database. I modeled customers, products, vendors, vendor-product relationships, orders, and order items with deliberate primary and foreign keys. My professor described the finished design as “beautiful.”
  3. Current direction
    AAS, Computer Programming Technology—in progress. Python and algorithmic problem-solving expanded my understanding of modern application development. I am continuing into mobile and game coursework to extend the systems I can build.

How I work

Thoughtful, resourceful, and production-minded.

I enjoy participating in planning, understanding the system behind a request, and carrying user-facing work across the stack.

01

Think across layers

I consider the user interface alongside data relationships, API behavior, accessibility, and the infrastructure that will support it.

02

Stay with the problem

When something breaks, I create a focused workspace, trace the failure across layers, and keep working until I understand both the fix and its cause.

03

Share the path

I organized weekly student coding sessions, shared solutions onscreen, and helped classmates isolate bugs. I value technical spaces where questions are welcomed.

I also use AI tools deliberately for exploration and implementation while keeping architecture, verification, accountability, accessibility, and broader impact in human hands.

What comes next

Ready to contribute—and keep growing.

I am pursuing my Computer Programming Technology degree while building, deploying, and operating my own products. I am looking for a full-stack software development opportunity where I can contribute now, learn from experienced teammates, and take meaningful ownership of software people actually use.

I work best when I can understand both the human need and the system behind it, whether I am joining an early product conversation or implementing a clearly defined requirement. I prefer remote work and remain open to hybrid or on-site opportunities with the right team.

Outside development, writing, art, and photography keep me observant, curious, and attentive to the details that shape how people experience the world.
